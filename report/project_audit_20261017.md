# 项目审计与收口计划（2026-10-17）

## 已确认

- 静态增强离线评估：accuracy 0.9362，macro-F1 0.9363。
- 动态离线评估：accuracy 0.9259，macro-F1 0.9303；独立测试视频 27 段，仍需扩充。
- PYNQ-Z2 已识别 `/dev/video0`、`/dev/video1`。
- 板端动态脚本已支持 `--product`，统一完成摄像头、推理、JSON 和 Jupyter 画面预览。
- 电脑端动态语音阈值固定为 0.30。
- Overlay/GPIO 已有通过记录，但 DMA 全帧传输仍受 16383 字节限制，不能宣称完整 FPGA 加速已完成。

## 当前风险

1. 真实摄像头静态识别明显低于离线增强集，说明训练与实时预处理仍有域差异。
2. 动态测试集偏小，尚不足以支撑最终准确率结论。
3. 项目电脑端 `.venv` 指向已不存在的 Python，当前不能在电脑上运行 pytest。
4. `report/`、`dataset/` 下有大量实验输出和版本目录，应在版本冻结后归档，不要直接删除。

## 电脑端已完成

- 板端动态摄像头默认改为 `/dev/video0`。
- 板端优先使用 Linux V4L2，避免误用 Windows DirectShow。
- 动态语音阈值改为 0.30，并显示实际播报文本。
- 保留历史数据、模型和报告，未做破坏性清理。

## 下一阶段顺序

1. 在有可用 Python 3.10/3.11 的电脑上重建虚拟环境并运行 `pytest`。
2. 将最新 `board_dynamic_live_json.py` 同步到板卡。
3. 用 `/dev/video0` 运行产品展示模式并确认 Jupyter 画面。
4. 补充每个动态类别至少 10 段独立测试视频。
5. 重新采集静态真实摄像头数据，统一 CPU/PL 预处理后再训练模型。
6. 单独完成 DMA 分块传输和 CPU/PL 逐像素对比，再做性能报告。
7. 版本冻结后再整理目录、更新 README 和制作答辩材料。
